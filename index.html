Invite Motor Mayhem Bot

Use this to generate a Discord invite link for your bot.
Good news: Inviting a bot does not require a Redirect URI.

INVITE LINK Paste Client ID → Generate → Open

Discord Developer Portal → Applications → Your App → General Information → Application ID.

8 = Administrator (simple). For safer perms, use: 274877990912 (Manage Roles, Kick/Ban, Read/Send).

REDIRECT URI What it is + when you need it
Redirect URI is only needed for OAuth2 login ("Sign in with Discord") — not for inviting a bot.

You only need it if you’re building a website where users log in with Discord. In that case, Redirect URI is the URL Discord sends users back to after they approve access (example: https://your-site.com/callback).

For Motor Mayhem dashboard bot control, you can ignore Redirect URI.
